## Selection Reasoning (Huashu 4d Order)

1. **Strong alone (单看就够好)**: Each of #1, #2, and #5 holds complete aesthetic gravity on its own without needing decorative gimmickry. #1 exhibits supreme gallery-level negative space and dignity. #2 delivers unmistakable Dutch graphic discipline where every border encodes structural meaning. #5 offers deep atmospheric command of developer tool aesthetics with sharp monospaced navigational rhythm.
2. **Mutually different skeleton + temperature + look family (彼此不一样)**:
   - **Skeleton**: #1 is an unhurried, off-center single column; #2 is a rigid multi-cell geometric grid with exposed rule lines; #5 is a fixed-sidebar dual-pane workstation feed.
   - **Temperature & Mood**: #1 is quiet, literary, warm, organic; #2 is bold, stark, neutral-cool, industrial; #5 is nocturnal, luminescence-accented, focused on code execution.
   - **Look family**: #1 is East-Asian editorial minimalism; #2 is European high-modernist constructivism; #5 is dark-mode developer documentation/engineering editorial. No two share a visual family.
3. **Not repeating current site look (不撞当前站)**: The current production site is light/dark frosted glassmorphism (`backdrop-filter: blur(18px)`) with slate-blue gradients. None of #1, #2, or #5 uses frosted glass, ambient blur layers, or generic SaaS card grids.
4. **At most one over-done (不用力过头 ≤ 1)**: None of the three resort to physical metaphors (skeuomorphic index cards, mock terminal CLI windows, fake ticket stubs). Information clarity increases directly from their structural discipline.

## The Alternates (备选方案)

- **Alternate A (#3 — Paco Coursey)**: Clean, exceptionally quiet reading stream. Retained as an alternate if the user prefers an even more understated, text-primary feed without the graphic tension of #2 or #5.
- **Alternate B (#4 — Anthony Fu)**: Authentic open-source developer documentation format with sage category tags. Retained if the user wants an explicit open-source ecosystem index rather than editorial art direction.
- **Alternate C (#6 — Sato Minimal Symbol)**: High-impact 50/50 graphic billboard. Retained if the user desires maximum visual volume and primary-color poster punch over nuanced hierarchy.
